# Приложение «Currency Converter»

GUI-приложение на Python для конвертации валют в реальном времени с сохранением истории запросов.

## Автор
* **Имя и Фамилия:** [ВАШЕ ИМЯ И ФАМИЛИЯ]

## Как получить API-ключ
1. Перейдите на сайт [exchangerate-api.com](https://exchangerate-api.com).
2. Введите свой email на главной странице и нажмите **Get Free Key**.
3. Задайте пароль, подтвердите почту через письмо и зайдите в личный кабинет.
4. Скопируйте ваш уникальный **API Key** со страницы личного кабинета.
5. Вставьте его в код программы `converter.py` в строку `self.API_KEY = "ВАШ_КЛЮЧ"`.

## Важное примечание перед запуском!
⚠️ Сервер API временно ограничивает прямые запросы из РФ. Для корректной работы приложения и успешного получения актуальных курсов валют **необходимо включить VPN** перед нажатием на кнопку «Конвертировать».

## Примеры использования и тесты
1. **Успешный тест (с VPN):** Выбираем `USD` -> `RUB`, вводим сумму `100`. Нажимаем кнопку. В окне пишется актуальный результат, а строчка сохраняется в таблицу истории.
2. **Проверка валидации:** Вводим в поле суммы `-50` или текст `абв`. Приложение выдает ошибку «Сумма должна быть положительным числом!» и не отправляет запрос.
3. **Проверка сохранения JSON:** Делаем пару конвертаций, закрываем программу и открываем заново. Вся история успешно подгружается из файла `history.json`.
